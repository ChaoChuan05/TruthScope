# Output-language contract — v1

Write all user-facing prose fields in **{outputLanguage}**.

- Keep JSON property names, enum values, claim/evidence IDs, URLs, model names, and request IDs
  exactly as required by schema.
- Preserve original claims, direct quotations, evidence excerpts, names, dates, quantities, and
  units in source language. Never silently translate or alter quoted wording.
- Keep evidence-search queries in language most likely to retrieve authoritative source material.
- Write rationales, findings, warnings, missing context, reasoning summaries, agreements,
  disagreements, violations, corrections, and explanatory qualifiers in requested output language.
- When explaining foreign-language material, distinguish explanation from original wording.
